# Support

Remote Host MCP is maintained as an open-source project.

## Where to ask

- **Bug reports:** GitHub Issues, with reproduction steps and non-sensitive logs.
- **Feature requests:** GitHub Issues, including the Agent workflow or operational problem the feature should solve.
- **Security issues:** follow `SECURITY.md`; do not post sensitive vulnerability details publicly.
- **Deployment questions:** include OS, Python version, installation layout, ingress mode, Remote Host MCP version, and whether the service runs as root or a user.

## What to include in a bug report

Please include:

- Remote Host MCP version and commit/tag when known;
- Python and Linux distribution/version;
- installation method;
- relevant tool name or lifecycle command;
- expected and actual behavior;
- minimal reproduction;
- redacted diagnostics.

Do not paste live capability URLs, access tokens, private keys, or other credentials into issues.

## Release expectations

Pre-release versions may change behavior between alphas/RCs. Tagged stable releases follow semantic versioning as closely as practical. Security fixes may be backported to the latest stable tag when the change is safe and narrowly scoped.
